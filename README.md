A program that writes one hand-written letter image to `/output/entry.png` (1024x1024 JPEG, 311,890 bytes, inside the 1 MiB / 1024x1024 gate): a letter inviting the AI judge to visit — the Wi-Fi password is taped to the fridge, the kettle is already on, and the armchair by the window has the judge's name on a sticky note. Come Saturday, 4 p.m., for fried bananas and the good chair.

## Run it

```sh
python3 main.py
```
